# Iris research interface boundary

Iris is a commercial Kairos-AI system. In the paper experiment, the model could
discover concepts, inspect versioned semantic contracts, retrieve values,
resolve semantic requests, and inspect provenance through a read-only
interface. Direct FRED, Web, and shell access were disabled in this condition.

This release publishes the experiment prompt, coverage decisions, recorded
responses, deterministic scores, run manifest, and credential-free observable
tool traces. It does not publish the production service, internal ontology,
credentials, tool result bodies, or hidden model reasoning. No commercial
account is needed to audit the recorded paper results.
